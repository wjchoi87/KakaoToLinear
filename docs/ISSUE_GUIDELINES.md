# 이슈 작성 지침

카카오톡 대화를 개발자가 바로 작업할 수 있는 Linear 이슈로 정리할 때 따르는 기본 지침이다.

- 대화에서 사실로 확인되는 내용만 요구사항으로 쓴다. 그럴듯한 해석은 참고사항에, 확정할 수 없는 것은 확인 필요에 둔다.
- 범위와 제외 조건("PC는 그대로", "모바일만")은 요구사항에 그대로 남긴다.
- 구현 방법(API, DB, CSS 구조 등)은 제안하지 않는다. 무엇을 바꿀지와 끝났다고 판단할 기준만 쓴다.
- 완료 조건은 원문에 없는 새 요구를 만들지 않는다.
- 첨부 이미지가 가리키는 화면, 요소, 오류 문구를 관련 요구사항과 연결해서 적는다.
- 제목은 한 줄로 어디를 어떻게 바꾸는지가 드러나게 쓰고, 대화에서 쓰인 언어로 작성한다.
